# Agent Instructions

## Test Command

- Run tests through `mise test` (= `cargo test --release --workspace`).
  Release mode matters: the suite runs full DKG ceremonies and takes many
  times longer in debug.
- Lint gate before any commit: `mise lint` (rustfmt check + clippy
  `--workspace --all-targets -- -D warnings`). CI enforces both.

## Conventions

- After doing your work always run `cargo fmt --all`.
- When adding a dependency, add it to the workspace `Cargo.toml` first and
  use `{ workspace = true }` in the crate.
- The toolchain is pinned in two places that must stay in sync:
  `rust-toolchain.toml` and `mise.toml`.
- If your change moves architecture (crate added/removed/repurposed,
  protocol flow changed, serialization changed, dependency policy
  changed), update `.agents/skills/opacity-ferveo-map/SKILL.md` and its
  mirror in `.claude/skills/` in the same PR. Do not add volatile detail
  there (function names, line numbers).

## Wire format is sacred

- Everything this library serializes (keys, transcripts, ciphertexts) is
  bincode-1-default wrapping arkworks compressed points, and it is
  consumed by deployed systems. `ferveo/tests/wire_format.rs` pins the
  format against golden vectors generated by earlier builds. If it fails,
  your change is a wire-format break: stop and surface it — never
  regenerate the fixture to make the test pass.
- `ferveo-tdec/src/hash_to_curve.rs` has RFC 9380 known-answer tests;
  the same rule applies.

## Dependency policy (deliberate pins — do not "fix" them)

- `rand` stays 0.8 and `rand_core` 0.6: ark-std re-exports rand 0.8 and
  RNGs flow into arkworks traits. Move only in lockstep with an arkworks
  upgrade.
- `bincode` stays 1.3.3: upstream is abandoned (3.0.0 is a compile-error
  tombstone); 1.3.3 is verified advisory-free and is the wire format.
- `miracl_core` is exact-pinned (`=`): its Fp2 serialization byte order
  changed between minor versions before; bump only with the KATs green.

## Consumers

- opacity-stack consumes these crates as rev-pinned git dependencies
  (`package = "ferveo"`). After landing changes here, update the `rev`
  in opacity-stack's workspace `Cargo.toml` and run its tests.
